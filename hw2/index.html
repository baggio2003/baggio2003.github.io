Homework 2: Toy ECC vs. Caesar Cipher & Cryptanalysis

Comparative implementation of Asymmetric Toy ECC Encryption and the Symmetric Caesar Cipher, featuring Statistical Frequency Cryptanalysis ($\chi^2$ & Bigrams) versus Algebraic ECDLP Attacks (Exhaustive & Baby-Step Giant-Step).

1. Encryption Schemes: Toy ECC vs. Caesar Cipher

We encrypt the exact same plaintext using two fundamentally different paradigms: an asymmetric scheme built upon the elliptic curve $y^2 \equiv x^3 + 7 \pmod p$ (the secp256k1 equation over a finite prime field) and the classical symmetric Caesar Cipher.

Scheme A: Toy ECC Encryption (ECDH / ElGamal)

Asymmetric
  1. Key Generation (Alice): Selects a secret scalar private key $d_A \in [1, N]$ and publishes her public key point $Q_A = d_A \cdot G$.
  2. Ephemeral Encapsulation (Bob): Picks a random ephemeral scalar $r$, computes ephemeral public point $R = r \cdot G$, and derives the shared curve point $S = r \cdot Q_A$.
  3. Character Masking: For each letter $m_i \in \{0, \dots, 25\}$, Bob derives step point $S_i = (r + i) \cdot Q_A = (x_{S_i}, y_{S_i})$ (or static $S$ in ECB mode) and masks: $$c_i = (m_i + x_{S_i}) \pmod{26}$$ The transmitted ciphertext is the pair $(R, \mathbf{c})$.
  4. Decryption (Alice): Using her private key $d_A$, Alice reconstructs the base shared point from $R$: $$S' = d_A \cdot R = d_A(rG) = r(d_A G) = r Q_A = S$$ She then computes $S_i$ and recovers $m_i = (c_i - x_{S_i}) \pmod{26}$.

Scheme B: The Caesar Cipher

Symmetric
  1. Key Setup: Alice and Bob must share the exact same secret shift integer $k \in \{0, \dots, 25\}$ over a pre-existing secure channel.
  2. Encryption (Bob): Shifts each alphabetical character $m_i \in \{0, \dots, 25\}$ uniformly modulo 26: $$c_i = E_k(m_i) = (m_i + k) \pmod{26}$$
  3. Decryption (Alice): Applies the inverse modular translation using the identical secret key $k$: $$m_i = D_k(c_i) = (c_i - k) \pmod{26}$$
  4. Statistical Footprint: Because the same offset $k$ is added to every character, the ciphertext histogram is simply a cyclic horizontal rotation of the plaintext histogram.

3. Statistical Cryptanalysis of the Caesar Cipher

Because the Caesar cipher preserves monographic and digraphic frequencies up to a cyclic shift $s \in \{0, \dots, 25\}$, we can recover the key automatically without human intervention by comparing decrypted candidates $D_s(C)$ against an English reference corpus:

$$\hat{k}_{\chi^2} = \arg\min_{s \in \{0,\dots,25\}} \sum_{i=0}^{25} \frac{\big(O_i(s) - L \cdot p_i\big)^2}{L \cdot p_i}, \qquad \hat{k}_{\text{N-gram}} = \arg\max_{s \in \{0,\dots,25\}} \sum_{j=1}^{L-1} \log P_{\text{bigram}}\big(D_s(c_j), D_s(c_{j+1})\big)$$

Effectiveness, Limitations & Method Comparison

  • Effect of Ciphertext Length ($L$): For $L \ge 40$ characters, monographic $\chi^2$ minimization achieves nearly $100\%$ key recovery accuracy. On very short ciphertexts ($L \le 10$), high sampling variance causes atypical letter distributions (e.g., short words lacking E or T), leading to false minima.
  • Monographic ($\chi^2$) vs. N-Gram (Bigram) Scoring: Bigram scoring captures structural transition probabilities (such as TH, HE, QU, while penalizing impossible pairs like JX or QZ). Combining monographic and bigram log-likelihoods significantly boosts accuracy on short strings ($5 \le L \le 20$).
  • Exhaustive Key Search (Brute-Force): Since $|\mathcal{K}| = 26$, enumerating all candidates is instantaneous ($O(26 \cdot L)$), but automating the selection still requires a statistical or lexical distinguisher (cannot decrypt zero-redundancy random strings).

4. Algebraic Attack on the Toy ECC Scheme (Restricted Key Space)

Unlike the Caesar cipher, polyalphabetic Toy ECC flattens letter frequencies. However, because the private key $d_A$ is restricted to a small range $[1, N]$, an attacker who intercepts the public parameters $(G, Q_A)$ and ciphertext $(R, \mathbf{c})$ can directly solve the Elliptic Curve Discrete Logarithm Problem (ECDLP):

$$\text{Find } \hat{d}_A \in [1, N] \text{ such that } \hat{d}_A \cdot G = Q_A \quad \Longrightarrow \quad \text{Compute } S = \hat{d}_A \cdot R \text{ and decrypt } \mathbf{c}$$

Algebraic Attack vs. Statistical Cryptanalysis

  • Deterministic vs. Probabilistic: The ECDLP attack verifies an exact mathematical identity ($\hat{d}G = Q_A$). It succeeds with $100\%$ certainty even if the message is 1 character long or consists of completely random bytes. Statistical attacks on Caesar require plaintext redundancy and fail on short or random inputs.
  • Why Infeasible on Production secp256k1: Real secp256k1 uses a 256-bit prime subgroup order $n \approx 1.158 \times 10^{77}$. Exhaustive search takes $O(2^{256})$ steps, and $O(\sqrt{n})$ algorithms (Pollard's $\rho$ / BSGS) still require $\approx 2^{128} \approx 3.4 \times 10^{38}$ curve operations—billions of times the age of the universe on modern supercomputers.

Restricted Key Space vs. Toy Design Flaws

  • Key-Space Weaknesses: A small bound $N$ enables $O(N)$ linear search and $O(\sqrt{N})$ Baby-Step Giant-Step (BSGS) or Pollard's Kangaroo. If the curve order is composite, Pohlig-Hellman reduces ECDLP to prime factors.
  • Structural Design Flaws (Independent of Key Size!):
    1. Static Masking (ECB Mode): If $S = rQ_A$ is applied statically to all letters ($c_i = m_i + x_S \pmod{26}$), the scheme degenerates into a Caesar cipher! An attacker breaks it via $\chi^2$ frequency analysis in milliseconds even if $d_A$ is a full 256-bit key.
    2. Nonce Reuse ($r_1 = r_2$): Encrypting two messages with the same ephemeral $r$ leaks $C^{(1)} - C^{(2)} \equiv M^{(1)} - M^{(2)} \pmod{26}$.
    3. Malleability (No MAC): Adding $\Delta$ to $c_i$ predictably shifts the decrypted letter by $+\Delta$.
