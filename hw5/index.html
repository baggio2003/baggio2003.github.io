Exercise 1

Lebesgue Measure Theory vs Riemann Darboux Sums

The fundamental shift from Riemann to Lebesgue involves rotating our perspective by 90 degrees: from slicing the Domain (X) to slicing the Range (Y).

1. Riemann (Vertical Domain Slices)

Partitions the domain $[a,b]$ into subsets $I_i$. It computes the integral as a sum of vertical rectangles:

$$ \int_a^b f(x) dx \approx \sum_{i=1}^N f(x_i^*) \Delta x_i $$

Failure case: The Dirichlet function oscillates infinitely between 0 and 1 on any interval. $\sup(f) = 1$ and $\inf(f) = 0$ everywhere, hence upper and lower Darboux sums never converge.

2. Lebesgue (Horizontal Range Bins)

Partitions the range into $y_j$. It groups all $x$'s that produce the same $y$, weighing $y_j$ by the Lebesgue measure $\mu$ of its preimage:

$$ \int f d\mu \approx \sum_{j} y_j \cdot \mu\big(\{x \mid f(x) \approx y_j\}\big) $$

Measure Zero: The set of rationals $\mathbb{Q}$ is countable. We can cover it with intervals of length $\epsilon/2^n$. The total length is $\sum \epsilon/2^n = \epsilon$. As $\epsilon \to 0$, the measure $\mu(\mathbb{Q}) = 0$. Thus, Dirichlet integrates to $0$.

Exercise 2

Normal CDF: Liouville, Taylor & Catastrophic Cancellation

1. Liouville's Theorem & Maclaurin Series

Because the antiderivative of $e^{-t^2}$ is non-elementary (Liouville, 1833), we express $\Phi(z)$ via the Error Function $\text{erf}(x)$. By expanding $e^{-t^2}$ into its Maclaurin series and integrating term-by-term, we obtain:

$$ \text{erf}(x) = \frac{2}{\sqrt{\pi}} \int_{0}^{x} \left( \sum_{n=0}^{\infty} \frac{(-1)^n t^{2n}}{n!} \right) dt = \frac{2}{\sqrt{\pi}} \sum_{n=0}^{\infty} \frac{(-1)^n x^{2n+1}}{n! (2n+1)} $$

This series converges for all $x \in \mathbb{R}$ mathematically. However, computational physics imposes hardware limits.

2. The IEEE-754 Catastrophic Cancellation Limit

When evaluating the Taylor series for large $|x|$ (e.g., $Z=4$), the term $x^{2n+1}$ grows exponentially before the factorial $n!$ can suppress it. The maximum intermediate term can reach $\sim 10^{15}$.

Because IEEE-754 Double Precision Float64 provides only 53 bits of mantissa ($\approx 15-17$ decimal digits), adding and subtracting these massive alternating terms to produce a final sum $<1$ strips away all significant digits. The result becomes pure computational noise.

// Taylor Series implementation vulnerable to Catastrophic Cancellation
function computeTaylorErf(x) {
    let sum = 0, term = x, n = 0;
    while (Math.abs(term) > 1e-15 && n < 80) {
        sum += term;
        n++;
        // Recursive term update: alternating sign, factorial div, polynomial grow
        term = -term * x * x * (2 * n - 1) / (n * (2 * n + 1));
    }
    return (2 / Math.sqrt(Math.PI)) * sum;
}
