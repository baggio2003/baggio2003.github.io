Theoretical Framework

1. Independence in Probability Theory vs. Statistics

Although governed by the same multiplicative structure, the concept of independence operates in two distinct epistemological regimes depending on whether we work in deductive probability theory or inductive empirical statistics.

A. Independence in Probability (Axiomatic / Deductive)

Defined on an abstract probability space $(\Omega, \mathcal{A}, \mathbb{P})$ where the true probability measure $\mathbb{P}$ is known a priori. Two events $A, B \in \mathcal{A}$ (with $\mathbb{P}(A), \mathbb{P}(B) > 0$) are stochastically independent ($A \perp B$) if and only if:

$\mathbb{P}(A \cap B) = \mathbb{P}(A)\mathbb{P}(B) \iff \mathbb{P}(B \mid A) = \mathbb{P}(B)$

For two discrete random variables $X \in \mathcal{X}$ and $F \in \mathcal{F}$, independence ($X \perp F$) requires that their joint distribution factorizes identically into the product of the marginals for every pair $(x_i, f_j)$:

$\pi_{ij} = \mathbb{P}(X = x_i, F = f_j) = \pi_{i\cdot} \, \pi_{\cdot j}$

Equivalently, the Mutual Information between the joint and product distributions vanishes: $I(X; F) = 0$.

B. Independence in Statistics (Empirical / Inductive)

In statistics, we observe a finite bivariate sample $\mathcal{D} = \{(x_k, f_k)\}_{k=1}^N$ arranged in an $R \times C$ contingency table with joint counts $n_{ij}$.

1. Descriptive Independence: Two sample variables are empirically independent iff all conditional relative frequencies equal the marginal relative frequencies:

$f_{j \mid i} = \frac{n_{ij}}{n_{i\cdot}} = \frac{n_{\cdot j}}{N} \iff n_{ij} = E_{ij} = \frac{n_{i\cdot} n_{\cdot j}}{N}$

2. Inferential Independence: Due to finite-sample variability, even data drawn from truly independent variables ($\pi_{ij} = \pi_{i\cdot}\pi_{\cdot j}$) rarely satisfies $n_{ij} = E_{ij}$ exactly. Independence is thus tested as a null hypothesis $H_0: \pi_{ij} = \pi_{i\cdot}\pi_{\cdot j}$ via Pearson's $\chi^2$ statistic.

Mathematical Formulation: Marginals, Conditionals & Pearson's $\chi^2$

Let $X$ take $R$ categories $\{x_1, \dots, x_R\}$ and $F$ take $C$ categories $\{f_1, \dots, f_C\}$. From the joint absolute counts $n_{ij}$, the marginal frequencies and conditional profiles are:

$$ n_{i\cdot} = \sum_{j=1}^C n_{ij}, \qquad n_{\cdot j} = \sum_{i=1}^R n_{ij}, \qquad N = \sum_{i=1}^R \sum_{j=1}^C n_{ij} $$ $$ P(F = f_j \mid X = x_i) = \frac{n_{ij}}{n_{i\cdot}}, \qquad P(X = x_i \mid F = f_j) = \frac{n_{ij}}{n_{\cdot j}} $$

Under the hypothesis of independence, $P(F = f_j \mid X = x_i) = P(F = f_j) = n_{\cdot j}/N$, which yields the expected frequency $E_{ij}$ in cell $(i,j)$:

$$ E_{ij} = n_{i\cdot} \cdot P(F = f_j) = \frac{n_{i\cdot} \, n_{\cdot j}}{N} $$

Karl Pearson’s (1900) Chi-Square Statistic sums the squared standardized residuals $r_{ij} = \frac{n_{ij} - E_{ij}}{\sqrt{E_{ij}}}$ across all $R \times C$ cells. Under $H_0$ as $N \to \infty$:

$$ \chi^2 = \sum_{i=1}^R \sum_{j=1}^C \frac{(n_{ij} - E_{ij})^2}{E_{ij}} = \sum_{i=1}^R \sum_{j=1}^C r_{ij}^2 \xrightarrow{\;d\;} \chi^2_{\nu}, \qquad \nu = (R - 1)(C - 1) $$

The asymptotic $p$-value is evaluated via the regularized upper incomplete gamma function $Q(\nu/2, \chi^2/2)$, while the normalized effect size is measured by Cramér’s $V$:

$$ p\text{-value} = \mathbb{P}(\chi^2_\nu \ge \chi^2_{\text{obs}}) = \frac{1}{\Gamma(\nu/2)} \int_{\chi^2_{\text{obs}}/2}^{\infty} t^{\frac{\nu}{2} - 1} e^{-t} \, dt, \qquad V = \sqrt{\frac{\chi^2}{N \cdot \min(R-1, C-1)}} \in [0, 1] $$

Algorithmic Implementation: Contingency Reduction & Exact $p$-Value

// 1. Programmatic Contingency Table & Chi-Square
function analyzeBivariate(records) {
    // Single-pass reduction of arbitrary (x, f) stream
    for (const { x, f, w = 1 } of records) {
        counts[x][f] = (counts[x][f] || 0) + w;
        rowMarginals[x] += w; colMarginals[f] += w; N += w;
    }
    // Expected frequencies E_ij & Pearson Chi-Square
    const E_ij = (rowMarginals[i] * colMarginals[j]) / N;
    const r_ij = (O_ij - E_ij) / Math.sqrt(E_ij);
    chi2 += r_ij * r_ij;
}
// 2. Exact p-Value via Incomplete Gamma Q(df/2, chi2/2)
function chiSquarePValue(chi2, df) {
    const a = df / 2, z = chi2 / 2;
    if (z <= 0 || df <= 0) return 1.0;
    // Switch between Power Series & Lentz Continued Fraction
    return (z < a + 1)
        ? 1 - gammaSeriesP(a, z)
        : gammaContinuedFractionQ(a, z);
}

Critical Epistemology

5. Statistical Association vs. Causality

Even when Pearson's $\chi^2$ test yields a tiny $p$-value ($p \ll 0.001$) and a large Cramér's $V$, rejecting $H_0$ only demonstrates statistical association (stochastic dependence): $P(X, F) \neq P(X)P(F)$. It does not prove that $X$ causes $F$ ($X \to F$).

1. Algebraic Symmetry vs. Causal Directionality

Both Pearson’s $\chi^2$ and Mutual Information are strictly symmetric with respect to $X$ and $F$:

$\chi^2(X, F) = \chi^2(F, X)$
$I(X; F) = I(F; X)$

A bivariate contingency table cannot distinguish between forward causation ($X \to F$), reverse causation ($F \to X$), or selection bias without external structural assumptions.

2. Confounding & Reichenbach’s Principle

By Reichenbach’s Common Cause Principle, if $X$ and $F$ are statistically dependent ($X \not\perp F$), an unobserved confounder $Z$ may be driving both ($X \leftarrow Z \to F$). Even if $X$ and $F$ are conditionally independent given $Z$ ($X \perp F \mid Z$), marginalizing over $Z$ creates a spurious association:

$P(X, F) = \sum_{z} P(z)\,P(X \mid z)\,P(F \mid z) \neq P(X)P(F)$

In Simpson’s Paradox, the sign of the association in the marginal table $(X, F)$ can even reverse completely when stratified across the levels of $Z$.

3. Observational vs. Interventional Conditioning

In Judea Pearl’s causal hierarchy, contingency tables only estimate the observational conditional distribution ("seeing $X=x$"), whereas causality is defined by the interventional distribution ("setting $do(X=x)$"):

$P(F = f \mid X = x) \neq P\big(F = f \mid do(X = x)\big)$

Establishing causality requires either a Randomized Controlled Trial (RCT)—which removes incoming confounding paths into $X$—or adjusting for a valid back-door covariate set $Z$.
